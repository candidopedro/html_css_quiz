# 🎨 Projeto de Testes — HTML & CSS

Projeto inicial para prática e experimentação com **HTML** e **CSS**, focado em estrutura, estilização e layout de páginas web.

---

## 📁 Estrutura do Projeto

```
projeto/
├── index.html        # Página principal
├── css/
│   └── style.css     # Estilos da aplicação
└── README.md         # Documentação do projeto
```

---

## 🚀 Como Usar

1. Clone ou baixe este repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd seu-repositorio
   ```

3. Abra o arquivo `index.html` diretamente no navegador, ou use uma extensão como o **Live Server** (VS Code) para visualização em tempo real.

## 🎯 Objetivo

Este repositório serve como ambiente de testes e aprendizado. Aqui você pode:

- Praticar a semântica do HTML com tags como `<header>`, `<main>`, `<section>`, `<footer>` e outras
- Experimentar propriedades CSS como Flexbox, Grid, animações e responsividade
- Testar diferentes layouts e componentes visuais

---

## 📌 Observações

- Este projeto **não utiliza JavaScript** — o foco é exclusivamente em estrutura e visual.
- **Sem dependências externas** — basta um navegador moderno para rodar.
- Ideal para quem está aprendendo a construir páginas estáticas do zero.
